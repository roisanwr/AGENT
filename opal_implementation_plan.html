Fondasi Opal
Setup input, agent step, dan dynamic routing
Input step
Form input user
  • Kolom tujuan bebas
  • Kolom konteks opsional
  • Dropdown kategori (opsional)
  • Upload referensi (opsional)
Agent step
Classifier + router
  • Baca & analisis tujuan user
  • Deteksi kategori otomatis
  • Tanya balik jika ambigu
  • Tentukan cabang tujuan
Dynamic routing
Routing logic
  • Kondisi per kategori
  • Fallback jika tak cocok
  • Path ke sub-agent
  • Log keputusan routing
Memory
Preferensi user
  • Nama / style pilihan
  • Kategori sering dipakai
  • Riwayat prompt dibuat
  • Simpan ke Google Sheets
Fase 2
Cabang-cabang spesifik
Sub-agent per kategori dengan fixed steps masing-masing
Cabang gambar
Image prompt
  • Style & medium
  • Subjek & komposisi
  • Mood / lighting
  • Aspect ratio & resolusi
  • Model target (MJ, DALL-E)
Cabang video
Video prompt
  • Durasi & format
  • Camera movement
  • Scene & transisi
  • Tone visual
  • Model target (Veo, Sora)
Cabang audio
Audio prompt
  • Genre & tempo
  • Instrumen & vokal
  • Mood & energi
  • Durasi target
  • Model (Suno, Udio)
Cabang coding
Code prompt
  • Bahasa & framework
  • Tujuan fungsi
  • Input / output spec
  • Batasan & constraint
  • Gaya (clean, verbose)
Cabang persona
AI character
  • Nama & latar belakang
  • Kepribadian & nada
  • Keahlian & batasan
  • Cara bicara
  • Konteks penggunaan
Cabang konten
Tulisan & narasi
  • Format & panjang
  • Audiens & platform
  • Tone & gaya bahasa
  • Tujuan konten
  • Contoh referensi
Cabang baru bisa ditambah kapan saja — cukup buat path baru di dynamic routing dan sub-agent step sendiri. Contoh berikutnya: pembelajaran, presentasi, iklan, email marketing.
