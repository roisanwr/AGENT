Cabang gambar / image
Target model: Midjourney, DALL-E, Stable Diffusion, Ideogram, Flux
Checklist kualitas wajib
  • Subjek utama harus disebut paling awal dan paling spesifik — bukan "wanita cantik" tapi "seorang wanita berusia 30an, rambut keriting pendek, ekspresi serius"Model image membaca token awal lebih kuat bobotnya
  • Sertakan medium / style secara eksplisit — "oil painting", "cinematic photography", "flat vector illustration"Tanpa ini model pilih default yang random
  • Sebutkan lighting — "golden hour", "dramatic side lighting", "soft diffused"Lighting adalah 50% dari mood gambar
  • Tambahkan kualitas teknis di akhir — "4K, highly detailed, sharp focus, award-winning"Booster kualitas yang aman di hampir semua model
  • Sertakan negative prompt untuk MJ/SD — hal yang TIDAK diinginkan harus dieksplisitkanMisal: "no blur, no watermark, no extra limbs"
Jebakan umum
Terlalu banyak subjek
Lebih dari 2–3 elemen utama → model kebingungan, satu elemen jadi diabaikan. Fokuskan ke satu hero element.
Gaya yang kontradiksi
"Realistic anime photography" → model bingung mau pilih yang mana. Pilih satu genre visual utama.
Ukuran tidak disebutkan
Aspek rasio sangat mempengaruhi komposisi. Portrait vs landscape vs square — harus ditentukan.
Contoh struktur prompt
[subjek detail] + [setting/latar] + [style/medium] + [lighting] + [mood/atmosphere] + [kualitas teknis] --ar [rasio] --neg [hal yang dihindari]
Cabang video
Target model: Veo, Sora, Kling, Runway, Pika
Checklist kualitas wajib
  • Deskripsikan camera movement secara eksplisit — "slow dolly in", "aerial drone shot pulling back", "static wide shot"Ini yang paling sering dilupakan dan paling berpengaruh
  • Tentukan durasi dan pace — "5 second clip, slow motion", "30 second montage, quick cuts"Tanpa ini model default ke durasi random
  • Deskripsikan aksi secara sekuensial — apa yang terjadi dari awal sampai akhir clipModel video butuh narasi temporal yang jelas
  • Sebutkan tone visual — "cinematic, warm tones", "dark noir, high contrast", "bright and cheerful"
  • Tentukan apakah ada suara/musik dalam brief — beberapa model bisa generate audio juga
Jebakan umum
Prompt statis seperti gambar
Prompt video harus mendeskripsikan GERAK dan WAKTU, bukan hanya visual diam. "Seorang pria berdiri di pantai" → flat. "Seorang pria berjalan perlahan menuju ombak, angin menggerakkan rambutnya" → jauh lebih baik.
Terlalu banyak scene dalam satu prompt
Satu prompt = satu continuous shot. Kalau mau multi-scene, buat prompt terpisah per scene.
Contoh struktur prompt
[camera movement + shot type] + [subjek + aksi sekuensial] + [setting] + [tone visual] + [durasi] + [kualitas]
Cabang audio / musik
Target model: Suno, Udio, MusicGen, ElevenLabs
Checklist kualitas wajib
  • Genre + sub-genre — bukan hanya "jazz" tapi "smooth jazz, bossa nova influence"Semakin spesifik semakin predictable hasilnya
  • Instrumen yang harus ada vs boleh tidak ada — "piano + bass, no drum kit"
  • BPM atau kata keterangan tempo — "120 BPM", atau "upbeat", "languid", "driving"
  • Mood dan konteks penggunaan — "background cafe ambiance", "epic battle theme", "melancholic solo"Konteks penggunaan sangat membantu model
  • Durasi target dan apakah perlu vokal atau instrumental
Jebakan umum
Referensi artis tanpa deskripsi
"Seperti Billie Eilish" → ambigu karena Billie punya banyak era/style. Deskripsikan elemen musikalnya: "whisper vocals, lo-fi bedroom pop, sparse arrangement, melancholic".
Contoh struktur prompt
[genre + sub-genre] + [instrumen utama] + [tempo/BPM] + [mood] + [konteks] + [durasi] + [vokal/instrumental]
Cabang coding
Target model: Claude, GPT-4o, Gemini, GitHub Copilot
Checklist kualitas wajib
  • Sebutkan bahasa + versi + framework secara eksplisit — "Python 3.11, FastAPI"Tanpa ini model mungkin pakai syntax versi lama
  • Deskripsikan input dan output yang diharapkan dengan contoh konkretIni yang paling mempercepat ketepatan output
  • Tentukan constraint — "harus bisa jalan tanpa library eksternal", "max 50 baris", "harus handle error"
  • Sebutkan gaya kode yang diharapkan — "dengan komentar penjelasan", "clean dan minimal", "production-ready"
  • Kalau ada kode existing, instruksikan untuk dimodifikasi bukan ditulis ulang dari nol
Jebakan umum
Tujuan terlalu abstrak
"Buatkan sistem login yang aman" → terlalu luas. Harus spesifik: auth method apa, session management bagaimana, framework apa, database apa.
Tidak menyebut konteks codebase
Kalau ini bagian dari proyek yang lebih besar, harus dijelaskan struktur dan konvensi yang sudah ada.
Contoh struktur prompt
[bahasa+versi+framework] + [tujuan fungsi 1 kalimat] + [input/output dengan contoh] + [constraint] + [gaya kode] + [konteks proyek jika ada]
Cabang persona / karakter AI
Target model: Claude, GPT-4o, Gemini — untuk sistem chatbot/asisten
Checklist kualitas wajib
  • Identitas harus konkret — nama, latar belakang singkat, "mengapa dia ada"Memberi anchor pada model agar karakter konsisten
  • Tentukan cara bicara dengan contoh — "berbicara santai, sering pakai analogi, hindari jargon teknis"
  • Definisikan batasan eksplisit — apa yang persona TIDAK akan lakukan atau katakanIni sama pentingnya dengan yang boleh dilakukan
  • Sertakan contoh respons ideal — 1-2 contoh Q&A untuk "kalibrasi" karakter
  • Tentukan konteks penggunaan — chatbot customer service, tutor, teman cerita, asisten produktivitas
Jebakan umum
Kepribadian yang kontradiksi
"Serius tapi humoris, formal tapi santai" tanpa penjelasan kapan — model akan random pilih salah satu. Harus ada aturan kapan switch tone.
Tidak ada contoh respons
Deskripsi persona tanpa contoh output nyata membuat model menginterpretasi sendiri — hasilnya bisa jauh dari ekspektasi.
Contoh struktur prompt
[identitas + latar] + [cara bicara + tone] + [keahlian + fokus topik] + [batasan] + [contoh Q&A] + [konteks penggunaan]
Cabang konten / tulisan
Blog, caption, script video, email, copywriting, dll
Checklist kualitas wajib
  • Format dan panjang harus eksplisit — "artikel 800 kata", "caption 3 paragraf pendek", "script 60 detik"Tanpa ini model pilih panjang sendiri yang sering tidak pas
  • Definisikan audiens secara spesifik — "pemula di bidang investasi usia 25-35", bukan hanya "orang umum"
  • Tentukan tujuan konten — edukasi, entertaintment, konversi, awareness, engagementTujuan menentukan struktur dan CTA
  • Sebutkan platform — Instagram, LinkedIn, YouTube, blog — karena gaya per platform berbeda
  • Berikan angle atau hook yang sudah dipikirkan, atau minta model generate pilihan angle duluAngle adalah pembeda antara konten biasa dan menarik
Jebakan umum
Tone yang tidak terdefinisi
"Tone profesional" masih terlalu luas. Spesifikkan: "seperti konsultan yang bicara ke teman lama — hangat tapi berbobot, tidak kaku, tidak pakai jargon corporate".
Tidak menyebut hal yang dihindari
Kalau ada kata-kata, topik, atau pendekatan yang tidak boleh muncul — harus ditulis eksplisit. Model tidak bisa menebak pantangan tanpa instruksi.
Contoh struktur prompt
[format + panjang] + [platform] + [audiens spesifik] + [tujuan konten] + [tone + gaya bahasa] + [angle/hook] + [hal yang dihindari]
