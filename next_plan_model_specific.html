Cara implementasi knowledge per model di Opal
1
Buat "model knowledge sheet" di Google Sheets
Satu sheet per model — berisi: sintaks unik, parameter yang didukung, hal yang harus dihindari, contoh prompt terbaik, dan batas karakter/token. Agent bisa baca ini via memory step.
2
Model selector step — otomatis + konfirmasi
Setelah routing kategori, agent rekomendasikan model berdasarkan konteks user. Tampilkan pilihan: "Untuk style yang kamu minta, Midjourney v6 paling cocok — atau kamu mau pakai model lain?"
3
Sub-agent generate — format sesuai model terpilih
System prompt generate step harus berisi instruksi spesifik per model: "Jika target Midjourney, gunakan sintaks --ar, --style, --no. Jika DALL-E 3, gunakan kalimat natural deskriptif tanpa parameter teknis."
4
Validasi format sebelum output
Tambahkan step validasi: cek apakah prompt yang digenerate sudah sesuai format model yang dipilih. Misalnya kalau target MJ, apakah sudah ada --ar? Kalau belum, agent isi otomatis dengan default yang masuk akal.
5
Update knowledge secara berkala
Model AI update fitur dan sintaksnya rutin. Knowledge sheet perlu di-maintain — idealnya ada "versi" di setiap baris agar tahu kapan info terakhir diperbarui.
Apa yang perlu masuk ke knowledge per model
Sintaks & parameter
  • Parameter unik yang hanya ada di model ini
  • Format penulisan yang benar
  • Nilai default vs nilai optimal
  • Parameter yang deprecated
Karakteristik model
  • Kekuatan (apa yang dia unggul)
  • Kelemahan (apa yang sering gagal)
  • Batas token / karakter prompt
  • Sensitivitas terhadap urutan kata
Best practices
  • Pola prompt yang terbukti bagus
  • Kata kunci booster kualitas
  • Urutan elemen yang optimal
  • Contoh prompt → output nyata
Yang harus dihindari
  • Kata / pola yang sering gagal
  • Konflik antar parameter
  • Hal yang trigger safety filter
  • Misconception umum user
